# OpenPet Manual Acceptance Checklist

- Load the unpacked extension from `dist/`
- Open `https://chat.deepseek.com/`
- Confirm the page is recognized and the overlay appears
- Send a message and watch the overlay state change
- Import `scratch/boba.zip` from the popup
- If multiple pets exist, switch the selected pet from the popup
- Confirm the overlay shows the imported pet after refresh
- Toggle overlay visibility off and on from the popup
- Clear the local pet cache and confirm the popup resets to no selected pet
- Confirm the page still behaves normally
